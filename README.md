# Arnavxy Tap

## How do I install these formulae?

`brew install arnavxy/tap/<formula>`

Or `brew tap arnavxy/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "arnavxy/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
